# GloBE XML Export

**MME Legal | Tax | Compliance** — in cooperation with Mutara

Converts the Swiss QDMTT 2024 Excel template to OECD GIR XML and encrypts it for ESTV submission. No software installation required — runs entirely in the browser.

See [`Documentation/GLOBE_XML_EXPORT.md`](Documentation/GLOBE_XML_EXPORT.md) for full documentation.
